03. Copy into gallery metadata

Add the thumbnail block to the corresponding entry in your project's gallery list. The values describe the crop, not the dimensions of the full image. The production gallery now applies these values to thumbnail previews. Copy them into the matching image entry in your front matter.

How the controls work

1× means fill the 4:3 frame with the smallest possible crop (equivalent to CSS object-fit: cover). For a wide image, the sides are already cropped; for a tall image, the top and bottom are cropped. Higher zoom enlarges the image further and reveals less of it.

The zoom limit is the smaller of 3× and the magnification that would display the source at native pixel size. If an image has to be enlarged even at 1× to cover the frame, no further zoom is offered. Position sliders are disabled whenever the image exactly fills that axis. On drag, movement stops at the source image edges, so there are no empty borders.
